# Documentation

The **Documentation** pane allows you to annotate any DRG element (Decision, Input Data, Business Knowledge Model, Knowledge Source, Decision Service) with free-text documentation.

This documentation is stored in the `description` attribute of the DMN element and is preserved when the file is saved.

## Usage

1. Select a single element on the DRD canvas.
2. The Documentation pane appears in the right panel.
3. Write or edit the documentation using the Markdown editor.

Documentation is useful for describing the business intent of a decision, the expected format of input data, or the purpose of a BKM.
