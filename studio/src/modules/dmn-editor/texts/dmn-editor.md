# DMN Editor

The DMN Editor provides a visual modeling environment for Decision Model and Notation (DMN) 1.5 diagrams. It supports Decision Requirements Diagrams (DRD), decision tables, literal expressions, and boxed expressions.

## Features

- **DRD Modeling** — Create and connect Decisions, Input Data, Business Knowledge Models, Knowledge Sources, and Decision Services on a visual canvas.
- **Decision Tables** — Define rules with inputs, outputs, and hit policies (UNIQUE, FIRST, PRIORITY, ANY, COLLECT, RULE ORDER, OUTPUT ORDER).
- **Literal Expressions** — Write FEEL expressions for simple decision logic.
- **Boxed Expressions** — Use Context, Invocation, List, Relation, and other CL3 expression types.
- **Validation** — Real-time structural validation of your DMN model.
- **Git Integration** — Diff, history, and merge support for `.dmn` files.

## Getting Started

1. Create a new `.dmn` file or open an existing one.
2. Use the DRD canvas to model your decision requirements.
3. Double-click a Decision to edit its expression (table, literal, or boxed).
4. Use the Property panes on the right to configure element details.
