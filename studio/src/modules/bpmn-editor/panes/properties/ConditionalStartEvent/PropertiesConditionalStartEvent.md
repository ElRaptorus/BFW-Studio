# Conditional Start Event

**Currently not supported.**

![Conditional Start Event](ConditionalStartEvent.svg)

The `Conditional Start Event` is a specialized [Start Event](help://bpmn/properties/start_event) for an `Event Subprocess` that is triggered, when the annotated `condition` becomes true.
The condition is modeled by using FEEL expressions.
