# Service Task

!["ServiceTask"](./ServiceTask.svg)

A service task is a task that uses a service, like a web service or an automated application, to complete its work.

Available implementation types:

- **HTTP Service Task** — sends HTTP requests to configured endpoints
- [Custom Service Task](help://bpmn/properties/custom_service_task) — extensible implementation via plugins
