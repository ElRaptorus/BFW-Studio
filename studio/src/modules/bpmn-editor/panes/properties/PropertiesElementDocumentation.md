# Documentation

The `Documentation` property allows you to annotate any BPMN element with free-text documentation.

This documentation is stored inside the BPMN XML as a `<bpmn:documentation>` element and is visible to anyone who opens the diagram. Use it to describe the purpose of an element, document business rules, or leave notes for other process designers.

The documentation editor supports **Markdown** formatting for rich text output.
