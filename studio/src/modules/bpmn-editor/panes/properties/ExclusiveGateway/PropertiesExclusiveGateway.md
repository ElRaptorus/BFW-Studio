# Exclusive Gateway

![ExclusiveGateway](ExclusiveGateway.svg)

![Gateway](Gateway.svg)

There are two symbols for the `Exclusive Gateway` (also called XOR Gateway).
Both symbols are a square standing on the top.
One symbol has an empty content and the other symbol has an "X" as content.
Exclusive gateways limit the possible results of a decision to a single path, which is determined by the accompanying circumstances.
The condition is specified at the outgoing [conditional flows](help://bpmn/properties/conditional_flow).
A gateway can both split and merge.
