# Intermediate Timer Catch Events

![Intermediate Timer Catch Event](TimerIntermediateEvent.svg)

The `Intermediate Timer Catch Event` is a specialized [Intermediate Event](help://bpmn/properties/intermediate_event) that can be used to delay the process for a certain amount of time.

When reached, the `Intermediate Timer Catch Event` will wait until the configured timer has expired. Only then will the process be continued.

There are two types of `Intermediate Timer Catch Events`:

- [Intermediate Date Timer Catch Events](help://bpmn/properties/timer_intermediate_event_date)
- [Intermediate Duration Timer Catch Events](help://bpmn/properties/timer_intermediate_event_duration).
