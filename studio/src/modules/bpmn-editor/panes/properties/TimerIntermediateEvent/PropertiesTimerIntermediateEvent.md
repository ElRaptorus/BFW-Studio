# Intermediate Timer Catch Event

![Intermediate Timer Catch Event](TimerIntermediateEvent.svg)

An `Intermediate Timer Catch Event` pauses the flow until its timer elapses, then continues. Choose the timer `Type` — **Date** or **Duration** — and enter its value in the `Definition` field. A repeating cycle is not available here.

- [Intermediate Date Timer Catch Event](help://bpmn/properties/timer_intermediate_event_date) — waits until a specific date and time
- [Intermediate Duration Timer Catch Event](help://bpmn/properties/timer_intermediate_event_duration) — waits for a delay
