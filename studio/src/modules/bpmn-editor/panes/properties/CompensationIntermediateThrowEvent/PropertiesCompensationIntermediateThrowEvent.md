# Compensation Intermediate Throw Event

![Compensation Intermediate Throw Event](CompensationIntermediateThrowEvent.svg)

> **Not executed by the current Engine.** You can draw and deploy this element, but the Engine will not run it. Avoid it in executable processes for now.

The `Compensation Intermediate Throw Event` is a specialized [Intermediate Event](help://bpmn/properties/intermediate_event) that requests `Compensation` of already-completed work. Tasks are compensated through their [Compensation Boundary Event](help://bpmn/properties/compensation_boundary_event).
