# Example Payload

Optional.
You can use this property to document a typical payload sent or received by the element.

Available on all message-related elements:

- **Catch side:** Message Intermediate Catch Event, Message Boundary Event, Receive Task
- **Throw side:** Send Task, Message Intermediate Throw Event, Message End Event

## Triggering Message Events

When triggering Message Events through the Debugger, the Example Payload is used to auto-fill the payload value in the trigger dialog.
