# Message Intermediate Throw Event

![Message Intermediate Throw Event](MessageIntermediateThrowEvent.svg)

The `Message Intermediate Throw Event` is a specialized [Intermediate Event](help://bpmn/properties/intermediate_event) that send out a specific `Message` to another `Process` when it is triggered.
The `Process` will not pause the flow while the `Message Intermediate Throw Event` sends the `Message`.
