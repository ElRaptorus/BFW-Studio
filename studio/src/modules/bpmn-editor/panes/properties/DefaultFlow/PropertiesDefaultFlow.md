# Default Flow

![Default Flow](DefaultFlow.svg)

The `Default Flow` is a specialized [Sequence Flow](help://bpmn/properties/sequence_flow) and indicates which outgoing path of an `Activity` or `Gateway` is taken if none of the conditions of [Conditional Flows](help://bpmn/properties/conditional_flow) is valid.
