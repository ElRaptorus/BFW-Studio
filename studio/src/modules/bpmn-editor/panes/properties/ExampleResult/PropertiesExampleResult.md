# Example Result

Optional.
You can use this property to document the result produced by this element — i.e. the activity output that downstream flow nodes receive.

Available on:

- **Business Rule Task** — expected decision result
- **Service Task** (including HTTP) — expected service response
- **Call Activity** — expected child process output

When debugging a process in the Studio, the Example Result is used to auto-fill result values in the Debugger, so you can step through the diagram without manually entering output data each time.
