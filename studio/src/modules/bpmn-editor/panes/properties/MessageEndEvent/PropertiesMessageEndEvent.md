# Message End Event

![Message End Event](MessageEndEvent.svg)

The `Message End Event` is a specialized [End Event](help://bpmn/properties/end_event) that sends a `Message` at the end of the `Process`.

Other Processes can listen for this `Message` with [Message Start Events](help://bpmn/properties/message_start_event), [Message Boundary Events](help://bpmn/properties/message_boundary_event) or [Intermediate Message Catch Events](help://bpmn/properties/message_intermediate_catch_event).
