# Link Intermediate Throw Event

![Link Intermediate Throw Event](LinkIntermediateThrowEvent.svg)

The `Link Intermediate Event`s are generally used for printing BPMN diagrams.
With the `Link Intermediate Event` the `Process` can be split into parts.
This `Link Intermediate Throw Event` defines the end of a page or section.
