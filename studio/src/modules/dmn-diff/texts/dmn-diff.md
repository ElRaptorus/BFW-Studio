## DMN Diff

The DMN Diff view shows a side-by-side comparison of two versions of a DMN file.

### DRD Comparison

Both versions are displayed as Decision Requirements Diagrams (DRD) side-by-side. Elements are highlighted to show what has changed:

- **Green**: Added elements
- **Red**: Removed elements
- **Yellow**: Modified elements (attribute changes)
- **Blue**: Moved elements (layout changes)

### Change Navigation

Use the navigation arrows in the title bar to jump between changes. The Change Overview pane on the right shows a structured list of all detected changes.

### History Preview

When opened from the file history, you can toggle between:

- **Diff mode**: Side-by-side comparison of the current and historical versions
- **Preview mode**: Read-only view of the historical version

Use the **Restore** button to revert the file to the selected historical version.
